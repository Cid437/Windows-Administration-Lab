Understanding Operating Systems & Virtual Machines What is an Operating System (OS)? An Operating System (OS) is the core software that runs a computer. It acts as a bridge between the user, applications, and hardware, allowing the system to function smoothly and efficiently. What Does an Operating System Do? An operating system is responsible for: Managing hardware resources like the CPU, memory, and storage Running and controlling applications and processes Handling files, folders, and data storage Providing security through user accounts and permissions Offering a user interface for interaction with the system Common operating systems include Windows, Linux, and macOS. What is a Virtual Machine (VM)? A Virtual Machine (VM) is a software-based computer that runs inside another operating system. It behaves like a real computer, with its own operating system, applications, and system resources. Why Use Virtual Machines? Virtual machines are commonly used to: Run multiple operating systems on one physical computer Test software safely without affecting the main system Learn and practice system administration Improve hardware efficiency and reduce costs Together, operating systems and virtual machines play a vital role in modern computing, enabling flexibility, security, and efficient system management. What is VirtualBox? VirtualBox is a free and open-source virtualization software that allows users to create and run virtual machines on a single computer. It enables multiple operating systems to operate simultaneously within a safe and isolated environment. Why Use VirtualBox? VirtualBox is commonly used because it allows users to: Run multiple operating systems on one device Test software and system configurations safely Learn and practice operating system management Save hardware costs by using virtual systems
